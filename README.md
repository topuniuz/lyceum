# ALASU — Academic Lyceum of Andijan State University

Official website project for the Academic Lyceum of Andijan State University (ALASU), planned for **alasu.uz**.

## Product direction

ALASU is being rebuilt as a premium, accessible institutional website inspired by the clarity and credibility of leading universities while maintaining its own identity.

### Public website
- Home
- About
- Directors & Management
- Teachers
- Students
- Academic Programs
- Admissions
- News
- Achievements
- Gallery
- FAQ
- Contact

### Languages
- English (default)
- O'zbek
- Русский

### Admissions
The website does not collect direct lyceum applications. Official applications are submitted through my.edu.uz. ALASU provides admissions information and a contact/request-a-call flow.

### Contact requests
Contact submissions will be stored in Supabase and made available to authorized administrators, with Telegram bot notifications planned for operational follow-up.

## Planned stack
- React + Vite
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- Node.js for server-side integrations where required

## Development principles
- Institutional, premium visual language
- User-first information architecture
- Responsive and accessible by default
- Content managed through an authenticated admin workspace
- No student/parent portal in the initial public website
- No direct admissions application workflow
